# RewriteLite for Windows · 轻改

Rewrite selected text in a floating editor, turn an instruction into a draft, and refine it without losing the current context. Connect your own AI provider or a local Ollama model. The app is free for personal, educational and internal business use. Available in English and Simplified Chinese.

**[Product website](https://thunderbrain.github.io/RewriteLite/) · [中文主页](https://thunderbrain.github.io/RewriteLite/zh/) · [Installation and updates](https://thunderbrain.github.io/RewriteLite/guide/)**

## Download

- [Windows installer](https://github.com/ThunderBrain/RewriteLite/releases/latest/download/RewriteLite-Setup.exe) — installs for the current user and adds a Start menu entry.
- [Portable ZIP](https://github.com/ThunderBrain/RewriteLite/releases/latest/download/RewriteLite-Windows.zip) — extract all files to a writable directory and start RewriteLite.exe.
- [Release notes and checksums](https://github.com/ThunderBrain/RewriteLite/releases) — use the checksum for the exact release you downloaded.

Windows 10 or 11 with .NET Framework 4.8 or 4.8.1. In the app, use **Settings → Software updates → Check for updates**. Save any draft and exit from the tray before upgrading.

## AI and privacy

Cloud writing requests go directly to the provider you choose. API usage may incur provider charges. For on-device processing, start a local Ollama model and use a loopback connection. The public edition supports API connections. See the [privacy notice](PRIVACY.md).
