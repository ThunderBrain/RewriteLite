How it works

From a sentence to a finished draft.

Rewrite a selection

Highlight a passage and open the floating editor. Pick a writing style, edit the result, then replace the selection in supported controls or copy it anywhere.

Compose from an idea

With double Ctrl enabled, press it with no text selected. Describe what you want to say in your own language. Compose uses the output language you chose in Settings.

Refine a draft

Ask for a warmer tone, a shorter ending, or one more detail. Refine remembers the current draft and its instructions. Starting a new task gives you a fresh context.

FAQ

Before you download

Which AI services can I use?

Connect an OpenAI, Anthropic, Gemini or DeepSeek API key, configure a compatible endpoint, or use an Ollama model installed on your own machine. Select and test the model in Settings.

Is RewriteLite free?

Yes. The desktop app is free for personal, educational and internal business use. Cloud providers bill API usage under their own terms. The public Windows edition uses API connections and does not include a ChatGPT subscription sign-in.

Can I use it locally?

Yes. Start Ollama with a local model and choose its localhost endpoint in RewriteLite. Writing requests then stay on your machine. With a cloud provider, the text goes directly to that provider.

What happens to my drafts and API keys?

Writing context stays in app memory. Selected text is sent when you trigger rewriting. Saved API keys are encrypted for your Windows user account. See the privacy notice for details about providers, clipboard use and diagnostics.

Can I update without losing settings?

Yes. Choose Settings → Software updates → Check for updates. Exit from the tray, then run the new installer. For the portable edition, extract the new ZIP over the previous version and keep the data folder.

Get RewriteLite for Windows

Choose the installer for a Start menu entry, or extract the portable ZIP to a writable folder.
