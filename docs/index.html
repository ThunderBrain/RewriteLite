How it works

From a sentence to a finished draft.

Rewrite a selection

Highlight a passage and open the floating editor. Pick a writing style, edit the result, then replace the selection in supported controls or copy it anywhere.

Compose from an idea

With double Ctrl enabled, press it with no text selected. Describe what you want to say in your own language. Compose uses the output language you chose in Settings.

Refine a draft

Ask for a warmer tone, a shorter ending, or one more detail. Refine remembers the current draft and its instructions. Starting a new task gives you a fresh context.

FAQ

Before you download

How small is RewriteLite, and what does it cost?

The Windows installer is under 3 MB and uses the system .NET Framework. The app is free for personal, educational and internal business use. Cloud model usage is billed under your provider’s terms.

Where does it work?

Open the floating editor from an email, browser or document with a global shortcut. Where an app exposes its selection, you can rewrite it directly. Replace the original in supported fields or copy the result.

Can I use my own API key or OpenRouter account?

Yes. Choose your provider in Settings → AI connection. For OpenRouter, choose OpenRouter and enter a key from your account, then connect, select a text model and test it. Presets also include OpenAI, Anthropic, Gemini and DeepSeek.

Can I use my ChatGPT subscription?

The public edition supports your own OpenAI API key. Direct ChatGPT sign-in and subscription usage are currently unavailable in the public edition.

Can I use it locally?

Yes. Start Ollama with a local model and choose its localhost endpoint in RewriteLite. Writing requests then stay on your machine. With a cloud provider, the text goes directly to that provider.

What happens to my drafts and API keys?

Writing context stays in app memory. Selected text is sent when you trigger rewriting. Saved API keys are encrypted for your Windows user account. See the privacy notice for details about providers, clipboard use and diagnostics.

Can I update without losing settings?

Yes. Use Settings → Software updates to check for a release. Save your draft, exit from the tray and run the new installer under the same Windows account in the existing location.

Is RewriteLite available for Mac?

The current installer supports 64-bit Windows 10 and 11. A macOS edition is planned.
