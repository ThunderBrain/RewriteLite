Windows 公开版 · 2026-11-18

什么时候发送文字

仅选中文字或打开空白写作窗口不会发送内容。点击划词图标或在选区按已配置的快捷键会开始改写。生成时，输入、写作风格与有关语言设置会直接发送到所选 AI 服务。继续修改还会把当前草稿及本次任务的近期上下文发送到原服务和模型。新任务独立开始。

模型服务与连接

连接或刷新模型会联系所选接口。测试连接只发送内置测试提示。云服务商会收到通常的网络信息、请求内容和所需的认证信息，其隐私、留存与计费条款适用。选择本机 Ollama 的回环地址时，写作请求交由本机模型服务处理。

本机设置、剪贴板与诊断

写作上下文只保存在程序内存中。公开版设置位于程序旁的 data/settings.public.json，并可能保留一个备份。API Key 通过 Windows DPAPI 为当前 Windows 用户加密。划词使用 Windows 辅助功能接口。「复制」会写入剪贴板，系统的剪贴板历史和同步设置仍然适用。部分输入框支持直接替换。技术错误可能生成只留在本机的诊断日志，包含错误标识和方法名，不包含原文、凭证和请求地址。位置为 %LOCALAPPDATA%/RewriteLite/logs。程序无遥测或广告 SDK。

网站、更新与删除

网站与发行下载托管在 GitHub。访问网页、检查和下载更新时，GitHub 会收到常规网络连接信息。本网站未加入分析脚本、广告或跟踪 Cookie。缺少兼容的 .NET Framework 时，启动器会在下载微软运行环境前征得同意。公开反馈对任何人可见，请勿附带个人文字或凭证。退出程序后可删除 data 文件夹中的设置和备份、清除本地诊断日志，并在服务商处撤销 Key。
