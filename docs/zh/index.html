使用方式

从一句原文，到一份定稿。

划词改写

选中一段文字，在旁边的悬浮窗里选风格、看结果、直接编辑。支持的输入框可以原位替换，其他位置可以复制后粘贴。

按想法起草

启用双击 Ctrl 后，在没有选中文字时双击，就能打开写作窗口。用熟悉的语言说出想法，按设置里的目标语言生成草稿。

在草稿上接着改

想要短一些、语气柔和一点，或补充一个细节，都可以继续提要求。当前草稿保留这轮上下文，新任务从头开始。

常见问题

下载前常见问题

言字旁有多轻？使用要付费吗？

Windows 安装包不到 3 MB，使用系统的 .NET Framework。桌面软件可免费用于个人、教学和单位内部工作。使用云端模型时，费用由你选择的服务商按账户规则收取。

可以在什么地方用？

全局快捷键可以从其他 Windows 应用唤出言字旁。能读取选区的应用支持直接划词改写；支持原位替换的输入框可以一键写回，其他位置可以复制结果。

怎样使用自己的 API 或 OpenRouter 账户？

在「设置 → AI 连接」选择服务商，填入自己的 API Key。使用 OpenRouter 时，选择 OpenRouter 并填写该账户生成的密钥，连接后可从模型列表中选择并测试。也支持 OpenAI、Anthropic、Gemini、DeepSeek 和兼容接口。

能直接使用我的 ChatGPT 订阅吗？

当前公开版可用自己的 OpenAI API Key 调用模型。直接登录 ChatGPT 并使用订阅额度尚未向本产品的公开版开放。

能在本机处理文字吗？

可以。启动本机 Ollama 模型，并在言字旁中选择 localhost 接口，写作请求就会留在这台机器上。选择云服务时，文字会直接发送给该服务商。

草稿和 API Key 怎么保存？

写作上下文只留在程序内存中。触发改写时才发送选中的文字。保存的 API Key 由当前 Windows 账户加密。服务商、剪贴板和诊断记录的细节见隐私说明。

升级后还保留设置吗？

可以。在「设置 → 软件更新」检查更新，下载后保存草稿并从托盘退出。使用同一 Windows 账户在原安装位置运行新版安装程序即可。
