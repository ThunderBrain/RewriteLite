使用方式

从一句原文，到一份定稿。

划词改写

选中一段文字，在旁边的悬浮窗里选风格、看结果、直接编辑。支持的输入框可以原位替换，其他位置可以复制后粘贴。

看示例
输入
关于预算的事情，我想说一下，也许我们可以考虑把会议改到明天。
结果
我们可以把预算会议改到明天吗？

按想法起草

启用双击 Ctrl 后，在没有选中文字时双击，就能打开写作窗口。用熟悉的语言说出想法，按设置里的目标语言生成草稿。

看示例
输入
给 Mia 写封简短的邮件，感谢她整理笔记，并告诉她我周四会发初稿。
结果
Hi Mia, thanks for putting the notes together. I’ll send you a first draft on Thursday.

在草稿上接着改

想要短一些、语气柔和一点，或补充一个细节，都可以继续提要求。当前草稿保留这轮上下文，新任务从头开始。

看示例
输入
我们可以把预算会议改到明天吗？
追加要求
给个具体时间，语气轻松一点。
结果
明天下午两点聊预算，你方便吗？

常见问题

语言、风格和模型

怎样用中文起草英文邮件？

在设置里把起草目标语言选为英语，然后用中文写下收件人、要点和语气。下次起草会沿用这个语言设置。

能保存自己常用的语气吗？

可以。在主界面打开「写作风格」，给风格起个名字，写下要求，例如「句子短一点，保留专业术语」。以后改写或起草时都可以选它。

怎样让写作请求留在本机？

启动 Ollama 和本机模型，在言字旁里连接它的本机地址，选择模型后就能开始写作。
