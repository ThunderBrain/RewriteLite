使用方式

改一段话，也能从头写。

改写选中的文字

选中想改的那段话，点旁边的小图标，挑一个合适的语气。满意后就复制结果，支持替换的地方还可以直接写回原文。

看示例
输入
咱们原本定在今天开预算会，我这边想问问，时间能不能往后挪一天？
结果
今天的预算会能改到明天吗？

从几个要点起草

不选中文字，按设好的快捷键（比如双击 Ctrl），就能打开空白小窗。如果在设置里把起草语言选为英语，用中文列几个要点就能写一封英文邮件。

看示例
输入
帮我给 Mia 写封短邮件，谢谢她整理笔记，告诉她我周四发初稿。
结果
Hi Mia, thanks for putting the notes together. I’ll send you a first draft on Thursday.

接着改这一稿

写得太长，或语气太正式？在结果下面补一句「短一点」或「像平时说话那样」，就能接着改。

看示例
输入
今天的预算会能改到明天吗？
修改要求
约明天下午两点，语气随意一点。
结果
咱们明天下午两点聊预算，方便吗？

常见问题

关于语言、风格和模型

怎么用中文写一封英文邮件？

在设置里把起草语言选为英语，然后用中文写下要点。比如「谢谢 Mia 的笔记，告诉她我周四发初稿」。下次起草时，言字旁会记住你的语言选择。

怎么留下自己常用的写作风格？

打开主界面的「写作风格」，给新风格起个名字，再写下要求，比如「用短句，保留专业术语」。下次写作时直接选它就行。

可以在本机处理文字吗？

可以。先在 Ollama 里启动模型，再到言字旁的设置里连接本机地址，选好模型就可以写了。
