使用方式

从一句原文，到一份定稿。

划词改写

选中一段文字，在旁边的悬浮窗里选风格、看结果、直接编辑。支持的输入框可以原位替换，其他位置可以复制后粘贴。

看示例
输入
关于预算的事情，我想说一下，也许我们可以考虑把会议改到明天。
结果
我们可以把预算会议改到明天吗？

按想法起草

启用双击 Ctrl 后，在没有选中文字时双击，就能打开写作窗口。用熟悉的语言说出想法，按设置里的目标语言生成草稿。

看示例
输入
给 Mia 写封简短的邮件，感谢她整理笔记，并告诉她我周四会发初稿。
结果
Hi Mia, thanks for putting the notes together. I’ll send you a first draft on Thursday.

在草稿上接着改

想要短一些、语气柔和一点，或补充一个细节，都可以继续提要求。当前草稿保留这轮上下文，新任务从头开始。

看示例
输入
我们可以把预算会议改到明天吗？
追加要求
给个具体时间，语气轻松一点。
结果
明天下午两点聊预算，你方便吗？

常见问题

下载前常见问题

言字旁有多轻？使用要付费吗？

Windows 安装包不到 3 MB，使用系统的 .NET Framework。桌面软件可免费用于个人、教学和单位内部工作。使用云端模型时，费用由你选择的服务商按账户规则收取。

可以在什么地方用？

写邮件、浏览网页或编辑文档时，都可以用全局快捷键打开悬浮窗。应用支持读取选区时，可以直接划词改写。支持替换的输入框可一键写回，其他位置可复制结果。

能直接使用我的 ChatGPT 订阅吗？

个人版已支持用自己的 ChatGPT 账号登录。我们计划为公开版申请 ChatGPT 集成。

能在本机处理文字吗？

可以。启动本机 Ollama 模型，并在言字旁中选择 localhost 接口，写作请求就会留在这台机器上。选择云服务时，文字会直接发送给该服务商。

草稿和 API Key 怎么保存？

写作上下文只留在程序内存中。触发改写时才发送选中的文字。保存的 API Key 由当前 Windows 账户加密。服务商、剪贴板和诊断记录的细节见隐私说明。

有 Mac 版吗？

目前发布的是 64 位 Windows 10 和 11 安装包。macOS 版已列入计划。
