使用方式

从一句原文，到一份定稿。

划词改写

选中一段文字，在旁边的悬浮窗里选风格、看结果、直接编辑。支持的输入框可以原位替换，其他位置可以复制后粘贴。

按想法起草

启用双击 Ctrl 后，在没有选中文字时双击，就能打开写作窗口。用熟悉的语言说出想法，按设置里的目标语言生成草稿。

在草稿上接着改

想要短一些、语气柔和一点，或补充一个细节，都可以继续提要求。当前草稿保留这轮上下文，新任务从头开始。

常见问题

下载前常见问题

可以使用哪些 AI 服务？

可连接 OpenAI、Anthropic、Gemini、DeepSeek 的 API，配置兼容接口，或使用本机已安装的 Ollama 模型。在设置中可获取模型列表并测试连接。

软件免费吗？

桌面软件可免费用于个人、教学和单位内部工作。云端 API 按服务商规则计费。公开 Windows 版提供 API 连接，未提供 ChatGPT 订阅账号登录。

能在本机处理文字吗？

可以。启动本机 Ollama 模型，并在轻改中选择 localhost 接口，写作请求就会留在这台机器上。选择云服务时，文字会直接发送给该服务商。

草稿和 API Key 怎么保存？

写作上下文只留在程序内存中。触发改写时才发送选中的文字。保存的 API Key 由当前 Windows 账户加密。服务商、剪贴板和诊断记录的细节见隐私说明。

升级后还保留设置吗？

可以保留。在「设置 → 软件更新 → 检查更新」下载新版，保存草稿并从托盘退出后运行新安装包。便携版覆盖解压到原目录，保留 data 文件夹。

下载 Windows 版轻改

安装版会添加开始菜单入口；便携版完整解压到可写目录即可运行。
