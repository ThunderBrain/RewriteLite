安装与更新言字旁

需要 .NET Framework 4.8 或 4.8.1。

安装言字旁

下载并运行 RewriteLite-Setup.exe。安装包不到 3 MB，会为当前 Windows 用户添加开始菜单入口。支持 64 位 Windows 10 或 11，使用 .NET Framework 4.8 或 4.8.1；缺少兼容环境时，启动器会询问是否从微软下载。

连接你的模型

进入「设置 → AI 连接」。用 OpenRouter 时，选择 OpenRouter，填入该账户的 API Key，点击「连接」，选择文字模型，测试后保存。其他服务使用相应的 API Key。本地运行可选择 Ollama 的 localhost 接口。

升级并保留设置

在「设置 → 软件更新 → 检查更新」下载新版，保存草稿并从托盘退出，再用同一 Windows 账户在原位置运行新版安装程序。早期便携版用户请从本页下载安装程序；如需迁移设置，可在应用退出后将原 data 文件夹复制到尚无设置的新安装目录。

校验下载

从官方 GitHub Release 下载，对照资产旁的 SHA-256。可在 PowerShell 中用 Get-FileHash 计算下载文件的哈希。首发 Windows 程序未签名，系统可能提示发布者未知。
