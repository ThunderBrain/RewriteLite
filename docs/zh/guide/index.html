安装与更新轻改

需要 .NET Framework 4.8 或 4.8.1。

选择安装方式

安装版为当前 Windows 用户安装并创建开始菜单入口。便携版请完整解压到可写文件夹，然后运行 RewriteLite.exe。支持具备 .NET Framework 4.8 或 4.8.1 的 Windows 10 和 11。缺少兼容运行环境时，启动器会在下载微软安装程序前询问。

连接模型

进入「设置 → AI 连接」，选择服务，填写 API Key，点击「连接」获取模型列表。选择文字模型，测试并保存。使用 Ollama 时，先在本机安装并运行模型，再选择 localhost 连接。

从旧版升级

在「设置 → 软件更新 → 检查更新」下载新版，等待程序校验文件。保存草稿，从托盘退出轻改。安装版用同一 Windows 账户运行新安装包；便携版将新 ZIP 完整解压到原目录，保留 data 文件夹。

校验下载

从官方 GitHub Release 下载，对照资产旁的 SHA-256。可在 PowerShell 中用 Get-FileHash 计算下载文件的哈希。首发 Windows 程序未签名，系统可能提示发布者未知。
