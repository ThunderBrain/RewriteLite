Install and update RewriteLite

Requires .NET Framework 4.8 or 4.8.1.

Choose a download

The installer sets up RewriteLite for your Windows user and adds a Start menu entry. With the portable ZIP, extract the entire archive into a writable folder and launch RewriteLite.exe. Windows 10 and 11 are supported with .NET Framework 4.8 or 4.8.1. If a compatible runtime is missing, the launcher asks before downloading the Microsoft installer.

Connect a model

Open Settings → AI connection. Choose a provider, enter its API key and click Connect to fetch available models. Choose a text model, test the connection and save. For Ollama, first install and start a local model, then choose the localhost connection.

Upgrade an existing installation

Open Settings → Software updates → Check for updates. Download the new release and let the app verify it. Save any drafts and choose Exit from the tray. For an installed copy, run the new installer under the same Windows account. For a portable copy, extract the new ZIP into its original folder and keep the data folder.

Verify a download

Download from the official GitHub release. Compare the file’s SHA-256 with the digest shown for that asset on GitHub. In PowerShell run Get-FileHash on the downloaded file. The initial Windows release is unsigned, so Windows may display an unknown-publisher warning.
