Install and update RewriteLite

Requires .NET Framework 4.8 or 4.8.1.

Install RewriteLite

Download and run RewriteLite-Setup.exe. The installer is under 3 MB and adds a Start menu entry for your Windows user. It supports 64-bit Windows 10 and 11 with .NET Framework 4.8 or 4.8.1. The launcher asks before downloading a missing runtime from Microsoft.

Connect your model

In Settings → AI connection, choose OpenRouter account and click Connect with OpenRouter. Sign in and approve in your browser. Back in RewriteLite, choose a text model, test it and save. If you already have a key, choose API Key, select OpenRouter in the provider dropdown and paste your key. For browser sign-in, match the localhost address shown in RewriteLite with the one on OpenRouter. The key label is RewriteLite · 言字旁.

Upgrade and keep your settings

Choose Settings → Software updates → Check for updates. Save your draft and exit from the tray before running the new installer in its original location under the same Windows account. If you used an earlier portable edition, download the installer here. To migrate your settings, exit the app and copy the old data folder into a new installation that has no settings yet.

Verify a download

Download from the official GitHub release. Compare the file’s SHA-256 with the digest shown for that asset on GitHub. In PowerShell run Get-FileHash on the downloaded file. The initial Windows release is unsigned, so Windows may display an unknown-publisher warning.
